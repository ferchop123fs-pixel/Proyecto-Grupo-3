# Índice de documentación de entrega

Este directorio reúne la documentación solicitada para la presentación del
sistema.

- `diagramas/arquitectura.md`: arquitectura general.
- `diagramas/modelo-datos.md`: relaciones principales de la base de datos.
- `manual/MANUAL_USUARIO.md`: guía por rol.
- `pruebas/TABLA_PRUEBAS.md`: matriz de pruebas.
- `DATOS_PRUEBA.md`: cuentas y datos disponibles.
- `AUDITORIA_FUSION.md`: auditoría técnica de la integración.
- `VALIDACION_FINAL.md`: validaciones realizadas.
- `CHANGELOG_CORRECCIONES.md`: historial de correcciones.
- `README_FUSION.md`: documentación técnica previa de la fusión.

Si un elemento ya está implementado directamente en el código, esta
documentación explica su ubicación y funcionamiento sin duplicar archivos
innecesarios.
